LwM2M demo server

A public instance of github.com/fiumaralabs/lwm2m, an open-source Go LwM2M 1.0 / 1.1 / 1.2 server. Point a device or a client at it and it shows up below.

Connect

Hostlwm2m.fiumaralabs.com
NoSeccoap://lwm2m.fiumaralabs.com:5683 (UDP)
DTLS-PSKcoaps://lwm2m.fiumaralabs.com:5684 (UDP, DTLS 1.2, CID supported)
PSK identity = your endpoint name, key 000102030405060708090a0b0c0d0e0f (hex, public: this is a demo, not security)
Bootstrapnone: configure the server URI directly

Anonymous and public. Everyone can see the endpoint names, so do not use a real IMEI or serial. Limits: 200 registrations, 10 per IP, lifetime capped at 3600 s (use a lifetime of at most that, or your client drops off the list before it sends an Update). The page can only list clients and read resources; it cannot write, execute or update firmware. Registrations are in memory and lost on restart.

Zephyr lwm2m_client sample 
west build -b <board> samples/net/lwm2m_client -- \
  -DCONFIG_LWM2M_APP_SERVER=\"coap://lwm2m.fiumaralabs.com:5683\" \
  -DCONFIG_LWM2M_APP_ID=\"my-zephyr-demo\"
# DTLS-PSK: -DEXTRA_CONF_FILE=overlay-dtls.conf and
#   -DCONFIG_LWM2M_APP_SERVER=\"coaps://lwm2m.fiumaralabs.com:5684\"
#   (the sample's default PSK is the demo key above)
Anjay demo 
./output/bin/demo --endpoint-name my-anjay-demo --lifetime 300 \
  --server-uri coap://lwm2m.fiumaralabs.com:5683
# DTLS-PSK:
./output/bin/demo --endpoint-name my-anjay-demo --lifetime 300 \
  --server-uri coaps://lwm2m.fiumaralabs.com:5684 \
  --security-mode psk --identity "$(printf my-anjay-demo | xxd -p)" \
  --key 000102030405060708090a0b0c0d0e0f
Leshan client demo 
java -jar leshan-client-demo.jar -n my-leshan-demo -l 300 \
  -u coap://lwm2m.fiumaralabs.com:5683
# DTLS-PSK:
java -jar leshan-client-demo.jar -n my-leshan-demo -l 300 \
  -u coaps://lwm2m.fiumaralabs.com:5684 \
  -i my-leshan-demo -p 000102030405060708090a0b0c0d0e0f
Wakaama lwm2mclient 
./lwm2mclient -n my-wakaama-demo -t 300 -h lwm2m.fiumaralabs.com -p 5683 -4
# DTLS-PSK (build with DTLS):
./lwm2mclient -n my-wakaama-demo -t 300 -h lwm2m.fiumaralabs.com -p 5684 -4 \
  -i my-wakaama-demo -s 000102030405060708090a0b0c0d0e0f
