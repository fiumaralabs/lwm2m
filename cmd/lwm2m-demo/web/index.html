LwM2M demo server

Connect an LwM2M device and look inside it

A public LwM2M 1.0, 1.1 and 1.2 server running fiumaralabs/lwm2m, an open-source server written in Go. Register a client, then browse its objects and resources by name, read values and watch them change.

Connect

Used in every command on this page. Endpoint names are public here: do not use a real IMEI or serial number.

Security

No bootstrap server: configure the server URI directly. DTLS 1.2, Connection ID supported. Lifetime is capped at 1 hour: use at most that, or the device drops off the list before its next Update.
